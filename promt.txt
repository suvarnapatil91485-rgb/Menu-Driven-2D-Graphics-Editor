\b 2D Graphics Editor Project - Prompts Used\b0\par
\par

1. Design and implement a menu-driven 2D Graphics Editor in C using a 2D character array as the drawing canvas.\par
\par
2. The canvas should initially be filled with the character '_' (underscore), and graphical objects should be drawn using the character '*' (asterisk).\par
\par
3. Write functions to draw:\par
\tab - Rectangle\par
\tab - Line\par
\tab - Triangle\par
\tab - Circle\par
\par
4. Add objects to the picture.\par
\par
5. Delete objects from the picture.\par
\par
6. Modify objects in the picture.\par
\par
7. Use a 2D array of characters to store the picture.\par
\par
8. Write a function to display the picture.\par
\par
9. Use separate canvases for Rectangle, Line, Triangle, and Circle.\par
\par
10. Add a feature to clear all canvases.\par
\par
11. Create a menu-driven interface for user interaction.\par
\par
12. Implement Feature 1: Rectangle Canvas.\par
\par
13. Implement Feature 2: Line Canvas.\par
\par
14. Implement Feature 3: Triangle Canvas.\par
\par
15. Implement Feature 4: Circle Canvas.\par
\par
16. Implement Feature 5: Delete Object.\par
\par
17. Implement Feature 6: Modify Rectangle.\par
\par
18. Implement Feature 7: Clear All Canvases.\par
\par
19. Provide compile and run commands for VS Code/Codespaces.\par
\par
20. Provide Git add, commit, push, and commit history commands.\par
